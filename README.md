# Python Return Values

## Explanation

The `return` statement is used to send a result from a function back to the place where the function was called.

A returned value can be stored in a variable, displayed, or used in another calculation.

## Problem Statement

Write a Python program that defines functions to calculate the sum, product, and square of numbers and returns the results using the `return` statement.

## Features

* Defines functions with return values
* Uses the `return` statement
* Stores returned results in variables
* Performs multiple calculations
* Demonstrates function reusability

## How It Works

The program defines three functions:

* `add()` returns the sum of two numbers.
* `multiply()` returns the product of two numbers.
* `square()` returns the square of a number.

The returned values are stored in variables and displayed.

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Define functions with `return`.
3. Read two numbers from the user.
4. Call the functions.
5. Store the returned values.
6. Display the results.
7. End the program.
